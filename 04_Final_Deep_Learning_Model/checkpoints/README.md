# Trained Model Checkpoints

The best trained model checkpoint `best_road_model.pth` (361 MB) is generated by `train.py`.

Due to GitHub's 100 MB file limit, large `.pth` checkpoint binaries are omitted from git tracking.
- Run `python train.py` to train the model from scratch on the CityScale dataset.
- Or place your trained `best_road_model.pth` file here.
